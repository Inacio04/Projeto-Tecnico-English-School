Inglês ijuí
  Projeto de site/software para escola de inglês, usado como material de avaliação para aprovação no estagio de Técnico de Informática.
  A ideia é usar este site como forma expandir os limites da escola, proporcionando a alguns alunos a opção de curso EAD.
  Tendo em vista as paginas para o portal do aluno e do professor.

  
  PORTAL DO ALUNO:
  Local onde o aluno recebera as atividades e vídeos aulas (Somente para assistir e receber atividades)

  
  PORTAL DO PROFESSOR:
  Local onde o professor poderá postar material como arquivos e vídeos para as aulas.

  O acesso só será liberado ao usuário, caso a compra do curso seja efetuada, assim através do login o aluno poderá acessar a plataforma.
